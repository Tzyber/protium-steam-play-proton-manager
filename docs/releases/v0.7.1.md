# v0.7.1

v0.7.1 räumt vor allem die Rust-Schicht auf. Der Code ist jetzt klarer in
kleinere Module geteilt, ohne die Sicherheitsgrenzen für Steam-Dateien zu
verändern.

Große Bereinigungen laufen in überschaubaren Schritten. Suche und Papierkorb
sind etwas verständlicher, außerdem wurden die Abhängigkeiten aktualisiert.

Keine neuen Berechtigungen, kein Hintergrunddienst und keine automatische
Reparatur.
