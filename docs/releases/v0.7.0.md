# v0.7.0

## Spiel-Fußabdruck

- Der Detail-Drawer eines Spiels zeigt den lokalen Speicherbedarf:
  Spieldateien, compatdata (Wine-Prefix) und Shader-Cache, plus die Summe.
  Gemessen wird nur auf Klick und nur Daten, die dem Spiel eindeutig
  zugeordnet werden können. Fehlende oder nicht messbare Teile bleiben
  unbekannt und werden nie als null ausgegeben.
- Ist ein externer compatdata-Pfad in den Startoptionen konfiguriert, wird
  er nicht mitgezählt und sichtbar gemeldet. Ist die Startkonfiguration
  nicht eindeutig verfügbar, bleibt compatdata ungeprüft und wird als
  solches angezeigt.

## Stabilisierungen und Bereinigung

- Der Cleanup meldet nicht lesbare Claim-Orte jetzt über einen strukturierten
  Existenz-Check statt über Fehlermeldungs-Erkennung; ein fehlender
  Papierkorb bleibt der Normalfall, ein echter Lesefehler bleibt sichtbar.
- Die AppID-, Tiefenlimit- und System-Compat-Pfad-Konstanten von TypeScript
  und Rust sind per Test aneinandergebunden; eine einseitige Änderung
  schlägt jetzt an.
- Entfernte tote Test-Helper in Rust; die Pfad-Validierung (blockierte
  Systempfade, Punkt-Pfade, Scope) bleibt direkt getestet.
- Manifest-Parser: der Installationsordner wird nur übernommen, wenn er
  sicher ist (keine Pfad-Trenner, kein NUL). Zeitstempel im Papierkorb
  werden auf sichere Ganzzahlen geprüft.
- Die englische README ist als eigene Datei verfügbar (README.en.md).
- Biome-Schema auf die installierte Version gehoben; die letzte bekannte
  Prüf-Info entfällt.

Keine neue Berechtigung, keine neue Funktion ohne Nutzeraktion, keine
automatische Reparatur.
