# v0.6.5

## sichtbarkeit für steam-eigene prefixes

- Der Cleanup zeigt jetzt, wie viel Speicher Prefixes von Steam-eigenen
  Runtimes und Proton-Builtins belegen, statt sie nur still auszublenden.
  Sie werden gemeldet, aber nicht zum Löschen angeboten: Steam legt sie bei
  Bedarf neu an.

Keine neue Berechtigung, keine Hintergrundüberwachung, keine automatische
Reparatur.
