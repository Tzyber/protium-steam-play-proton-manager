# v0.4.4

## Fix: GE-Proton-Tools ließen sich nicht löschen

Steam schreibt selbst einen Default-Eintrag mit appId 0 ins
`CompatToolMapping` (config.vdf). Der Lösch-Durchlauf rief für diesen Eintrag
die App-ID-Validierung auf, die 0 fail-closed ablehnt — jeder
GE-Proton-Löschvorgang brach mit `appId 0 rejected` ab. Der Eintrag wird jetzt
übersprungen (er ist keine Zuordnung zu einem Spiel), Regressionstest
abgesichert.
