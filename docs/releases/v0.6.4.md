# v0.6.4

## cleanup- und löschfixes

- Der Cleanup zeigt keine Wine-Prefixes von Steam-eigenen Proton-Paketen
  mehr an (z. B. Proton 11.0, Proton Experimental). Die gehören zu Proton
  selbst und sind keine Löschkandidaten.
- Verwaiste Einträge zeigen jetzt den Spielnamen aus Steams Konfiguration
  statt nur der App-ID. Nur wenn Steam keinen Namen kennt, bleibt die ID
  sichtbar.
- Wird eine Löschung blockiert, weil das Spiel installiert ist, nennt
  Protium den Spielnamen statt nur der App-ID.

Keine neue Berechtigung, keine Hintergrundüberwachung, keine automatische
Reparatur.
